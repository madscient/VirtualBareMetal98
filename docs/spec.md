# 仕様

読者: 開発者・AI。要件と、確定した仕様だけを書く。方式は [design.md](design.md)、経緯は [worklog.md](worklog.md)。

## 目的

フロッピーディスクから直接起動するアプリ（OS を介さないベアメタルアプリ）を、
実機の PC-98x1 上で、ディスクイメージファイルから動かす。

## 動作環境（ホスト）

- 80386 以上の CPU を搭載した PC-98x1
- MS-DOS。CPU がリアルモードで起動しているか、VCPI を提供する EMM ドライバ（EMM386 など）の下で起動していること
  （VCPI のない仮想86モニタの下では止まる）。XMS ドライバ（HIMEM.SYS など）が常駐していること（ゲストのメモリを
  XMS から確保する。XMS なしの経路は [worklog.md](worklog.md) の残作業）
- ノーマルモードで動いていること。ハイレゾモードは対象外（テキスト VRAM と GDC の番地が違う）。EPSON の互換機は
  除外しない（設計で NEC 固有の振る舞いに依っていない。実物では未確認）

## 仮想マシン（ゲスト）

CPU を仮想86モードにし、その中に仮想 PC-98 を作る。ゲストに見せる構成は PC-9801VM 相当とする。
ただしサイクル正確性（実行速度、タイミング）は担保しない。

「PC-9801VM 相当」は次のように解釈している（[design.md](design.md) の D9）。ハードウェアはホストの
実物をそのまま使い、ゲストから見える構成情報を PC-9801VM に揃える。ホストにあって PC-9801VM にない
機能（EGC、256 色モードなど）を隠すことはしない。

| 項目 | ゲストに見せる構成 | 備考 |
| --- | --- | --- |
| CPU | V30。V30 固有の命令はモニタが代行する | 代行できる範囲と限界は [design.md](design.md) §14。`-v30 off` ではホストの CPU がそのまま見える |
| メインメモリ | 640KB | ホストの下位メモリとは別に確保する |
| 拡張メモリ | なし | PC-9801VM 相当であることから導いた |
| FDD | 2 台（ドライブ 0・1） | 中身はホストのファイルシステム上のイメージファイル |
| HDD | なし | ホストの HDD はゲストに見せない。ホストのストレージの割り込みも、ゲストには渡さない（未実装。worklog.md の残作業 10） |
| DMA | 仮想の DMA コントローラ（未実装。計画は worklog.md の残作業 10） | ゲストの設定は実物のコントローラに届かない。転送はモニタが代行する |
| DIP スイッチ・メモリスイッチ | 起動時のホストの値。オプションで上書きできる | ゲストが読む値をモニタが差し替える |
| 機種判別・装置の有無のフラグ | PC-9801VM。装置の有無はホストの実物に合わせる | BIOS ワークエリアの初期値 |
| サウンド BIOS | ホストの実物。`-sbrom` で ROM イメージに差し替えられる | 置く番地は C8000h か CC000h |
| I/O ポート | ホストの実物。`-iotrap` で番号を読み替えられる | 読み替えはゲストの I/O 命令の番地だけ |
| 表示・音・キーボード・タイマなど | ホストの実物 | ROM BIOS もホストのもの |

## コマンド

```
VBM98 [-fdd0 <ファイル>] [-fdd1 <ファイル>] [-v30 on|off] [-dipsw <16進6桁>] [-memsw <16進16桁>] [-ss <名前>]
      [-sbrom <ファイル>[,C8|CC]] [-iotrap <ゲスト>=<ホスト>[,...] | -iotrap <ファイル>] [-log <ファイル>[,<秒>]]
```

| オプション | 内容 | 省略時 |
| --- | --- | --- |
| `-fdd0 <ファイル>` | ドライブ 0 にイメージを入れる。起動はこのドライブから | 起動前にファイル選択を開く。取り消したら終了する |
| `-fdd1 <ファイル>` | ドライブ 1 にイメージを入れる | 空（ディスクなし） |
| `-v30 on` / `-v30 off` | V30 エミュレーション（V30 固有の命令の代行と、ゼロ除算の戻り番地）の有効・無効。範囲は [design.md](design.md) §14 | `on` |
| `-dipsw <16進6桁>` | DIP スイッチ SW1・SW2・SW3 の値を、この順に 2 桁ずつ。各バイトは NP21/W の設定ファイル（DIPswtch）と同じ値が同じ意味。`*` の桁はホストの同じ桁の値を映す | ホストの現在値で、SW2-8 だけ OFF（GDC 2.5MHz）。ホストの値どおりにするには `-dipsw ******` |
| `-memsw <16進16桁>` | メモリスイッチ 8 個の値を、1 番から順に 2 桁ずつ。`*` の桁はホストの同じ桁の値を映す | ホストの現在値 |
| `-ss <名前>` | スクリーンショットのファイル名の先頭（4 文字まで。英小文字は大文字にする） | ドライブ 0 に最初に入れたイメージのファイル名の先頭 4 文字 |
| `-sbrom <ファイル>[,C8\|CC]` | サウンド BIOS の ROM イメージ（16KB が普通。32KB まで）をゲストに見せる。置く番地は `C8`（C8000h）か `CC`（CC000h） | なし（ホストの実物）。番地を省くと CC |
| `-iotrap <ゲスト>=<ホスト>[,...]` | ゲストの I/O ポート番号をホストのポート番号に読み替える。番号は 16 進 1〜4 桁、コンマで複数 | なし |
| `-iotrap <ファイル>` | 読み替えの定義ファイル。1 行に `<ゲスト> <ホスト>`（16 進、空白区切り、行末は CRLF）を並べたテキスト。空行は無視 | なし |
| `-log <ファイル>[,<秒>]` | 診断ログ。本体の表示（起動時の情報、INT 1Bh の呼び出し、リセット、停止時のダンプ）を標準出力に加えてファイルにも書く（既存なら追記。1 行ごとに DOS に書き戻す）。秒を付けると、その間隔でゲストの位置・割り込みの回数・直近のイベントを書く心拍を入れる | なし |

- オプション名と値の大文字・小文字は区別しない。同じオプションを繰り返したら後のものが有効
  （`-iotrap` も同じ。一覧とファイルは併用しない）
- イメージが開けないときはメッセージを出して終了する
- `-dipsw` と `-memsw` はゲストにだけ作用する。ホストの DIP スイッチとメモリスイッチは読むだけで、
  変えない（実機のメモリスイッチは電池で保持され、DIP SW2-5 が ON のあいだはライトプロテクトされている）
- `-dipsw` を省略すると、ゲストにはホストの DIP スイッチがそのまま見えるが、SW2-8（グラフィック GDC のクロック）だけは
  OFF（2.5MHz）に見せる。ゲストは PC-9801VM 相当で、VM の GDC は 2.5MHz だけなので、5MHz の設定のホストでも 2.5MHz を
  前提にしたソフトが動く。`-dipsw` を書いたときは書いた値どおり（`*` はホストの値）
- `-dipsw` の `*` が映せるのは、ホストのポートから読める SW2 の全部と SW1-1・SW1-3・SW1-8・SW3-8。
  他のビットは 0（ON）になる（[design.md](design.md) §15）
- `-iotrap` の値に `=` があれば一覧、なければファイル名とみなす。読み替えの表は 64 個まで。16 ビット幅の
  I/O では読み替え先のポート + 1 を上位バイトにする
- `-sbrom` は ROM の内容を見せるだけで、サウンド BIOS の割り込み（INT D2h）の登録は行わない

## ホットキー

ゲストの実行中に効く。

| キー | 動作 |
| --- | --- |
| CTRL + GRPH + HELP | VM メニュー（仮想マシンのメニュー）を開く。下の 5 つを選べる |
| CTRL + GRPH + テンキーの 0 | ドライブ 0 の取り出し・入れ替え（イメージファイルの選択） |
| CTRL + GRPH + テンキーの 1 | ドライブ 1 の取り出し・入れ替え（イメージファイルの選択） |
| CTRL + GRPH + COPY | スクリーンショットの保存（下の「スクリーンショット」） |
| CTRL + GRPH + DEL | リセット（イメージから再起動。問い合わせなし。実機のリセットと同じ組み合わせ） |
| CTRL + GRPH + STOP | 仮想マシンの終了（問い合わせの後） |

- VM メニューの項目は、ドライブ 0・1 のディスク交換、スクリーンショットの保存、終了、リセット。終了とリセットは
  問い合わせの後
- メニューとファイル選択のあいだゲストは一時停止し、テキスト画面は退避してから復元する。グラフィック表示は
  GDC のコマンドで消し（VRAM には触らない）、閉じるときにゲストが設定していた表示の状態に戻す。音源は止めない
  ので、鳴っていた音はそのあいだ鳴り続ける
- ファイル選択の一覧には .fdi .nfd .fdd .hdm .img を出す。全ファイルの表示に切り替えられる
- メニューと問い合わせの文言は日本語

## 機能

| 機能 | 内容 |
| --- | --- |
| 起動 | ドライブ 0 のイメージの IPL から仮想 PC-98 を起動する |
| FDD アクセス | アプリの FDD BIOS 呼び出しを仮想86モードで横取りし、イメージの内容で応える。書き込みは BIOS 呼び出しのたびにイメージファイルへ反映する |
| ディスク交換 | ホットキーでアプリを一時停止して画面を退避し、ホストのファイルシステムからイメージを選ばせる。選択後に画面を戻して再開する |
| V30 エミュレーション | V30 固有の命令をモニタが代行する（範囲は [design.md](design.md) §14 の「代行する命令」と「合わせる振る舞い」） |
| スイッチ | DIP スイッチ・メモリスイッチの値を、ホストの設定と無関係にゲストへ見せる |
| リセット | アプリが CPU リセットをかけたら（FFFF0h へ飛んだら）、ホットキー CTRL + GRPH + DEL、または VM メニューのリセットで、仮想マシンをイメージから再起動する。表示系、ベクタ表とワークエリア、メモリスイッチと DIP スイッチの値、割り込みマスクは起動時の状態に戻し、RAM の残りは消さない（実機のリセットと同じ）。ドライブ 0 が空ならファイル選択を開く |
| サウンド BIOS | `-sbrom` の ROM イメージを C8000h か CC000h に見せる |
| I/O の読み替え | `-iotrap` の表に従い、ゲストの I/O ポート番号をホストの番号に読み替える |
| アプリの停止 | ゲストが割り込み禁止のまま HLT を実行したら（アプリが自分で止まった）、VM メニューを開いて終了かリセットを選ばせる |
| 終了 | ホットキーで仮想マシンを終了し、MS-DOS のプロンプトに戻る |
| スクリーンショット | ホットキー（または VM メニュー）で、表示中のグラフィック画面とテキスト画面を別々の PNG にしてホストのカレントディレクトリへ保存する。テキスト側は文字のない画素を透明にする。ファイル名は `<名前>###G.PNG`（グラフィック）と `<名前>###T.PNG`（テキスト）。`<名前>` は `-ss` の値、`###` は 001 から 999 で空いている最小の番号 |

対象外: FDC を BIOS を通さず直接操作するアプリ。

## 対応ディスクイメージ

| 形式 | 由来 | 拡張子の例 |
| --- | --- | --- |
| FDI | Anex86 | .fdi |
| NFD r0 / r1 | T98-Next | .nfd |
| FDD | Virtual98 | .fdd |
| RAW（ヘッダなし） | SL9821 など | .hdm ほか |

形式は拡張子ではなくファイルの中身で判定する。RAW として受け付けるサイズは 1.25MB / 1.21MB / 1.44MB /
720KB / 640KB の 5 種。構造と解釈は [disk-image-formats.md](disk-image-formats.md)。

対応予定（未実装）: D88（.d88 ほか）。計画は [worklog.md](worklog.md) の残作業 8。

| 2026-10-08 | `-dipsw` の省略時は、ホストの現在値で SW2-8 だけ OFF（グラフィック GDC は 2.5MHz）。`-dipsw ******` でホストの値どおり | 実機（PC-9821Cr13、SW2-8 が ON = 5MHz）で、2.5MHz 前提のゲームの表示が `-dipsw` の指定で直った（利用者の報告）。5MHz を前提にしたソフトが見つかったら見直す |
